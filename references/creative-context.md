# 创作背景与本版范围

本项目来自作者对多图组织、主体固定、音乐与信息递进的创作实践。以下是表达方向的背景，具体作品以当次选题为准。

作者希望把大量可生成图片组织成短视频中的高密度视觉表达：人物或主题可以稳定，文字、理由、场景与情绪随音乐推进。单帧是可编排的素材，不要求每一张都模拟连续摄影运动。选题可能是世界演化、信息逐层增加，也可能是情绪变化；具体表达由当次选题提供。

本版先沉淀已做过的裁切、锚点检测、可选配色排序、音乐起音候选、曝光保护与 Remotion 转场。Agent 的工作是理解图片承担的信息，再用这些工具决定顺序、选段、停留与转场力度。

无需在 skill 中先实现整个创作平台，也无需强制作者先做固定数量的作品或实验。以后新作品暴露问题，再把确实有用的处理方法收进同一 skill。
