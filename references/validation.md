# 本版验证记录

2026-10-25，Windows / Python 3.11 / 本机 Remotion 4.0.534，使用已有依赖与 Chrome，未安装新依赖。该记录证明工具可执行和已查项目的结果，不代表任意素材都具有同样的视觉质量。

- 原 ZIP 的 70 张图全部逐张核对源 SHA256、ZIP 原始顺序、输出尺寸，以及与源图中心裁切的像素相等。
- 通用 anchor 脚本对完整 70 张图得出 66 保留、4 排除、0 待复核；排除 img-0013、img-0023、img-0029、img-0038，与旧标题过滤一致。另用合成双锚点验证偏移剔除、低分保留、整组不可靠和全排保护。
- preserve、explicit 子集和 color 模式实跑；12 张子集的颜色邻接代价 11.4234→5.63325，仅是指定指标下降。异常尺寸拒绝、1080×1440 像素保持验证通过。
- 17.5 秒钢琴样本的 57 个起音候选与旧版时间完全一致。取消曲目专属排除后 52 暂接纳、5 low；原人工特例后是 50，不声称 52 个都听证正确。非零分析起点检查通过。
- 模板 TypeScript 和 9 项时序/schema 检查通过；有/无 mask 的 press、pulse、bounce 静帧均渲染检查。无 mask 的双层收缩露边问题已修正默认居中 overscan。
- 集成 8 张真实裁切图片及 8 个钢琴事件，源音频 0.056644..3.2 秒，导出 189 帧 / 60fps 的 1080×1440 MP4，包含 AAC 音轨，完整解码通过。检查了帧 0、30、43、100、188 的画面。没有将这个约 3.15 秒的技术小样当作新的完成选题或视听认可。
- BGM 抖音下载在并入前已验证同一播放器 MP3 的字节哈希、时长和解码；汽水公开试听此前实测成功，迁入时移除了本机路径依赖并增加非空目录保护。没有据此声称全部链接均可批处理。
